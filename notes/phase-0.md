# Phase 0 — Git and GitHub

## Concepts learned

- Repository
- Branch
- Commit
- Pull Request
- Merge
- Clone
- Push
- Pull

## Git workflow

1. Clone repository
2. Create branch
3. Make changes
4. Check status
5. Stage changes
6. Commit changes
7. Push branch
8. Create pull request
9. Review
10. Merge

## Objective

Use Git and GitHub to manage the development of BusinessOS and future software projects.
